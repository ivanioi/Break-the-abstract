# 介绍

在软件开发过程中，学习新的工具时，如果只是停留在技术文档，总是有恼人的问题时不时的在应用过程中冒出来， 与此同时，用起来心中也没有底！

该项目通过 IDE 插件 + 文档的方式来记录源码分析笔记(比如 Intellij IDEA MyCodeTutor Plugin  +  AsciiDoc)，

该项目目前只是作为源码分析笔记聚合仓库!

# 用法

如何记录源码分析? 如何阅读分析笔记?

无论工具源码由什么编程语言实现，我们都基于 IDE Plugin + 文档的思路来进行源码分析，笔记记录.

所以源码分析方式受限于使用的插件，通过使用的插件 + 文档阅读分析笔记.

以下主要介绍各类编程语言使用的 IDE 插件，以及文档工具.

## Java 源码 + Intellij IDEA

* 使用 MyCodeTour Plugin 分析源码
* 使用 AsciiDoc 记录分析笔记

```
bta/.tuors  空文件(不可删除)
bta/[language]/[target-source-code]/assciidocs      文档根目录
bta/[language]/[target-source-code]/.tours          MyCodeTutor 根目录
bta/[language]/[target-source-code]-verification/   独立可运行的 Java 项目, 提供示例验证对源码的分析
```
